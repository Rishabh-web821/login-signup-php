# Login Signup System

## Overview
Login Signup System is a web-based authentication application developed using PHP, HTML, and CSS. It allows users to register and log in through a simple and user-friendly interface.

## Features
- User Registration
- User Login
- Form Validation
- Responsive User Interface
- Authentication System
- Clean and Simple Design

## Technologies Used
- PHP
- HTML5
- CSS3

## Project Structure
```
login-signup-php/
├── index.php
├── login.php
├── signup.php
├── style.css
└── README.md
```

## How to Run
1. Download or clone the repository.
2. Install XAMPP or WAMP.
3. Copy the project folder to the `htdocs` directory.
4. Start Apache server.
5. Open the project in your browser.
